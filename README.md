# Thomani Consulting

Marketing website for **Thomani Consulting** — civil engineering, construction management, and tender pricing services.

**Live site:** [jackychabalala.github.io/thomani-consulting](https://jackychabalala.github.io/thomani-consulting/)

## Stack

Plain HTML, CSS, and JavaScript. No build step or framework.

## Project structure

```
├── index.html          # Main page
├── styles.css          # Site styles
├── variables.css       # Design tokens / CSS variables
├── main.js             # Interactions and animations
├── images/             # Logos, team photos, project gallery
│   └── aluminium/      # Aluminium works portfolio photos
├── pdf/                # Downloadable project documents
└── README.md
```

## Local preview

Open `index.html` in a browser, or serve the folder with any static server:

```bash
npx serve .
```

## Deploy

This site is hosted with **GitHub Pages** from the `main` branch of this repository.
